# 朝代人物参考库：精简生成与复用规则

[English](dynasty-reference-workflow.en.md)

按朝代、行业和常见身份选择性别。士兵、差役、店小二、镖师按常规选男款；六朝不单列女式劳动衣裤或女兵号衣。女性日常劳作角色可搭配本朝已有常服。已移除的专款不计缺项。

## 存量复核与新增素材共用规则

1. **先找同期同用途的造型。** 按分期、地域、身份、年龄与场合，逐款实际查找至少两部对应朝代经典剧目的同类造型，有可比画面时逐张查看。缺少匹配镜头时记录查过的剧名、检索内容和结果，再按第 6 条处理。记录剧名、人物、来源页和画面可见部位，选一套完整造型作主参考。只见上半身就只确认上半身，背面、内衬分别记录可见依据或创作推定。
2. **按角色看整套，按部件入库。** 对照主参考检查衣身与领袖的主辅色、内外层次、材质光泽，以及发髻、冠帽、饰物和鞋的搭配。鲜活程度以剧照中能辨认的色彩与质感为准，素衣也保留素衣的层次。正、斜、侧、背四张独立图须呈现同一套衣物或头饰。服饰去人物和支架，鞋履可保留。后续核查中，素材和现有剧照都能看清鞋履时顺带比对，看不到就跳过；此前已处理的款式无需为鞋履回查。
3. **同朝代先去重。** 并排比较同角色、同用途的各季四视图。领襟、袖型、轮廓、叠穿及身份标志高度相似时只留一款，季节写为适用标签。能看出独立罩衫、护甲、毛领或厚夹层等实质区别才另留；仅换色、改季节名或提示词写了不同厚度，均共用原款。
4. **选代表款并清理。** 优先保留来源最贴合、四视完整一致、轮廓细节清楚的一款。先迁移角色搭配与已证实的季节、朝代引用，再删除重复条目及其独占图片，记录旧 ID 到保留 ID 的对应关系并检查资源和角色覆盖。缺少可比剧照时按第 6 条判断去留。
5. **核查与修正在同一批次完成。** 对服饰、内衬、发型头饰和姿势，能确认配色、形制、搭配、动作或展示错误时，按主参考直接修图或换图；确认同朝重复或多余时按第 4 条合并或删除。确认有代表性的角色或用途缺项时，先查现有可复用素材；确无合适素材就直接生成、裁为四张独立视图并入库。季节标签数量不构成补图理由。
6. **以实际入库结果验收。** 缺少直接参考（含零张剧照）时，依次参考同期实物或图像、相近身份与用途的造型、库内已核实的同类款；结合四视图选最可信方案，当批保留、修图、合并或删除并结案。记录推定的具体部位、理由和实际使用的来源，标注“创作推定”。推定只说明依据强弱。已有图与选定方案一致时保留；有差异时实际修图或重新生成；有代表性缺项时生成新款并交付四张独立视图。单纯缺参考不留待审。修改后逐角目检，更新主目录、角色引用、审核状态和预览目录，检查图片链接及角色覆盖。批次汇报分别列出实际换图、新增、合并、删除数量和仍待核的原因。

**待办：全库逐款核查完成后，再跨时期比较同角色。** 将同用途、同年龄版型的候选放在一起，对照各自时期的剧照。衣型和穿法相似、身份标志及所带配件均适用时，择一列为“通用”，只列已核实的适用朝代。品级纹章、冠制、发式或礼仪用途有实质差异时保留对应部件；衣服能共用而冠帽有别时，只合并衣服。

## 快速使用约定

本指南是后续朝代任务的统一执行依据，已吸纳 2026-11-09 唐朝的去重、季节分类、儿童保留、僧衣整合和主要身份头饰规则。用户在本项目中输入“宋朝，按唐朝逻辑整理”时，按本指南输出完整规划；输入“宋朝，按唐朝逻辑生成首批”时，先盘点再执行已授权的首批素材。这里的“自动”指助手遵循规范接续任务，不表示网页已接入自动生图。

核心关系：**人物方案 = 时期与地域 + 常规身份／性别／年龄 + 场合／季节 + 共享内衬 + 适配外衣 + 发型头饰 + 姿势／可选道具。** 各部件独立选择；角色是搭配关系，图片单位是去重后的衣型或头饰。

| 部件 | 生成依据 | 不展开的维度 | 展示要求 |
| --- | --- | --- | --- |
| 外衣 | 轮廓、剪裁、层次、防护、礼仪形制的实质差异 | 不按角色机械复制，不因换色新增 | 无人物纯服装，保留男女与童装比例区别 |
| 内衣内衬 | 领襟、袖型、长短、衬裤／内裙、系结结构 | 不按角色、身份、四季复制 | 无人物独立内搭，穿法示例另标 |
| 冠帽盔 | 该朝代的身份、场合、形制与等级 | 不按四季复制，不按每个角色各造一顶 | 独立物件，无脸、头颈与肩膀 |
| 发髻饰物 | 发髻结构、年龄需要、日常／劳作／礼仪差异 | 不以换脸或发色作为新款依据 | 头发与饰物，无脸、皮肤和人体底座 |
| 姿势、道具 | 动作与实际使用需要 | 不跟着每套服装重新生成 | 与服装、头饰分别选取 |

所有新增素材均交付正面、斜侧、侧面、背面四张独立图。下文唐朝数量和名称是当前案例，不能将其作为其他朝代的固定配额或历史形制清单。

## 默认执行原则

给出一个朝代时，先整理代表性角色和可复用衣型，再按需分批生成独立素材。**不再按“角色 × 男女 × 四季 × 内外衣”全量生图。** 角色覆盖、四季搭配方案和独立衣型是三个不同维度；多个角色、多个季节可以引用同一组图片。

本规则适用于后续汉、宋、明及其他朝代。唐朝筛选结果是方法示例，不是其他朝代必须达到的数量，也不能将唐风素材直接改名用于其他朝代。这里的“完备”指约定范围内有代表性衣型和角色搭配可用，不代表穷尽一朝所有服饰。

这是供人或助手执行的生成规范；网站没有自动考证或生图服务。唐朝精选服装已按本规则归档非核心款并转换为纯服装四视图；另按用户选择恢复 8 组儿童外衣，已转换为纯服装四视图并保留童装比例，页面同步采用衣型数量统计；其他朝代后续按此方法逐批处理。

## 新制衣装的色彩与材质标准

默认展示该时代新制、干净衣装的参考效果，不以泛黄、褪色、灰雾或出土文物旧化效果表现“古代”。保持身份、品级与场合对应的色系；朴素、深色和低饱和本身不等于错误，不能为了鲜艳把劳动衣改成锦缎、把深色官服改成浅色。

- 宫廷礼服、宗室盛装与织绣：色彩清晰、层次分明；新生成时要求真实丝缎反光和金线细节，避免统一哑光灰褐滤镜。
- 日常、童装：颜色干净自然，保留棉、麻、丝等材质区别，不默认 `dusty`、`faded` 或 `aged`；特定灰色或素色设计仍可保留。
- 劳动、僧道日常与甲衣：维持朴素与材质真实性，暗部可辨认，不凭颜色修改身份或军阶。
- 内衬：保留本白、米白及原有淡色，避免过曝纯白和过强饱和。
- 同一组四视图采用相同色彩标准，导出的单张图与页面预览一致，不只加网页滤镜。

当前库按用户选择进行本地批量校色：固定用途参数、小幅提亮中间调、保色相增彩、保护浅色背景和高光；不重画衣型、纹样或模拟新增丝绸高光。原始生图提示词保留，校色记录另存 `output/color-refresh/`；历史准确性仍需单独复核。

后续按剧照编辑的 11 组已单独记录于 `output/tv-costume-review/`，不再沿用“仅本地校色”的当前状态。影视参考流程如下：

- 2026-11-15 用户新要求：每种服饰先查对应时期的多部经典影视剧，求同存异；不能一个朝代只绑定一部剧，也不能自行拼配色。此要求覆盖存量修图和补图，优先于此前仅作本地增彩的处理方式。
- 以“分期／地域 + 衣型 + 身份等级 + 场合 + 性别／成人童装比例”为比较单位。优先找到至少两部剧中的可比造型；同一剧的多篇转载不算多部剧。没有同类样本时明确缺证，不拿无关剧照凑数。
- 求同：记录跨剧反复出现的主色、衣襟袖缘、内外层和纹样配色关系；这只是影视视觉共性，不等于历史事实。存异：保留有来源的特色色组及其分期、身份、场合，不混色平均，不按换色新增衣型。
- 每个拟修改 ID 要有来源页面、剧名与版本、人物或明确定位、可见衣物区域、主辅色与配色位置、参考范围及未显示部分。可读的颜色名称即可；未经像素取样不得声称是精确色号。
- 先审阅具体图片，再选择一套完整、有来源的配色用于该款四视图。检索摘要、商品同款、海报人物拼图、夜景滤镜以及版本未核图不能直接充当整套服饰配色依据。影视服装的背面设计延展另记，不把演员人体带入素材。
- 内衬、儿童款、冷门衣型也单独核对，不从外衣颜色或成人服自动推导；只有一部剧或没有对应造型时标为“待补参考”，继续其他有依据的款式。元代题材须区分前元蒙古、元初、元末武侠；不能把《成吉思汗》的前元造型当元代官服依据。
- 当前逐项检索与多剧对照入口为 `output/tv-palette-audit/index.html`。`queries.json` 与 `search/` 是检索候选，不代表逐款审定；`decisions.json` 中通过的配色记录才可用于本轮入库。已有未匹配剧照的新图保持草稿，不能因已生图而绕过配色核对。
- 先核对剧名、版本、人物、衣型和场合，再比较颜色；宣传组合图不得称为同一镜头。只拿到公开剧照时，不填写未经确认的集数或时间码。
- 同名用途分类内也可能有不同衣型，不能因为都是宫廷礼服就把黑红衣裳改成金色叠袍；颜色不同本身不证明原款错误。
- 仅改善灰暗可以本地校色；改变衣型、纹样或丝绸反光需实际编辑图片。四个视角同时更新，并保留季节厚薄、叠层等功能区别。
- 明确写出参考了配色、纹样还是结构。背面、遮挡与季节变化是设计延展；影视服装不能替代朝代制度和等级证据。
- 沿用现有 ID 和分类，更新当前提示词，旧提示词及旧校色记录转为历史。剧照留在研究目录，不能混进原创素材库；仅保留必要的旧图比较小样。

## 一、确定时期与资料范围

- 写明朝代、分期、地域与主要场景。用户只说朝代时，先列重要分期差异，选择一个明确标注的代表性范围开始，不一次铺开所有分期。
- 查询博物馆馆藏、考古报告、同时代图像和制度文献，记录具体来源与适用范围。时代题材设计、研究推断与经资料支持的形制分别标注。
- 历史身份、便于检索的通俗称呼、文学影视角色分开。格格不套用到宋代；唐宋题材的“镖师”按影视创作或护送商旅者处理，不称为已证实的镖局制服。
- 同名衣物在不同朝代不默认同形；不同分期只有出现明确结构或制度差异时才新增素材，其他差异先写成资料说明。

## 二、角色与常规性别

先检查五大类：宫廷宗室、官府军旅、市井民生、家宅人物、江湖创作；宗教、医疗、艺术等按实际需求列入。角色清单用于检索与组合，不是一人一套制服的生图清单。

以下是本库默认选题规则，不是断言历史上不存在例外。按常规处理，不为少数个案自动增加另一性别；用户明确指定时再单独扩展。

| 默认范围 | 代表性角色 |
| --- | --- |
| 男 | 皇帝、宗室男子、皇子、公子、文官、书吏、书生、将领、士兵、差役、店小二、船工、一般工匠、郎中、乡绅 |
| 女 | 皇后、妃嫔、王妃、公主、宫女、小姐、丫鬟／侍女；格格仅在相应时代范围内 |
| 按需男、女 | 掌柜／店铺经营者、商贩、农人、普通家仆、伶人／乐师、儿童、老人 |
| 名称拆分后确定 | 宫女为女、内侍为男；道士为男、道姑为女；其他宗教人物按对应身份另列 |
| 江湖创作 | 大侠／游侠、镖师／护送商旅者沿用当前男士范围；其余角色按当前选题确定，不默认男女各一套 |

“可选男、女”不等于必须同时生成。女性织工等有明确职业选题时单列，不能由“一般工匠默认男”推断所有工艺职业都仅限男性。儿童比例与成人分开；老人优先复用适配的成人衣型，不能只因换白发或面容新增服装组。

## 三、以衣型为素材单位

### 外衣

满足以下任一实质差异，才考虑新增：领襟与开合结构、袖型与袖长、衣长与轮廓、裙裤结构、叠穿层次、保暖构造、职业防护装备，或有资料依据且现有素材无法表达的礼仪等级装饰。

仅换颜色、脸、角色名称、季节标签或不可见的面料说明，不另建衣型。先对比现有图片，再决定复用或新增；不凭名称不同、提示词不同或文件哈希不同判定造型独特。明显不同的官服、礼服、甲衣、宗教服不能只因都是长袍就合并。

每组记录可复用角色及限制。复用须匹配时代、性别造型、场合、身份、结构和叠穿关系；普通长袍可用于多个日常人物，不能据此将官服或宫廷礼装无条件分配给平民。

### 季节

**季节是适用标签，不是覆盖配额。允许某种衣型只收录一款或部分季节，不要求四季满格。** 无候选只表示当前筛选没有适用素材，不能自动列为缺项；只有明确缺少独特结构或必要用途时才进入补图清单。不得为消除空格而把未考证款强行标成四季通用。 外衣按下列实际差异取舍，既不强制每个角色四套，也不强制三套：

| 类型 | 保留条件 | 常见搭配季节 |
| --- | --- | --- |
| 薄单层款 | 基础衣型成立，春夏仅换色或面料描述时共用 | 春、夏，随地域调整 |
| 叠穿款 | 背心、罩衫等使轮廓或层次明显改变 | 春、秋或较凉场景 |
| 保暖款 | 厚袄、护肩、毛领、披风等有可见结构区别 | 冬或寒地场景 |
| 礼仪／职业款 | 场合、制度或装备产生独特结构 | 按需跨季使用 |

四季方案可以引用相同素材 ID，并说明增减层次；只有当前素材确实无法表达的差异才排入生图。共用披风等外层只在叠穿关系适配时复用，不凭季节标签认定可搭。

### 内衣内衬

内衬按版型共享，**不按角色、身份或四季重复生成**。重点区分短／长中衣、领襟、袖型、系结方式、衬裤／内裙、裹身式内搭等。需要明显不同的保暖或防护结构时，作为独立功能款说明理由，不能重新展开四季矩阵。

肚兜／兜肚须单独检查：胸腹前片、挂颈及腰后系带不能用长围裙叠中衣替代，也不与宋代抹胸直接合并。先选有依据的朝代和版型，成人基础款与儿童比例按需区分，不自动分男女或四季；刺绣、颜色变化本身不构成新衣型。当前 I011 为长围裙式内搭创作图，不作为独立肚兜已覆盖的证据。清代肚兜依据见[国家博物馆研究](https://www.chnmuseum.cn/yj/xscg/xslw/201812/t20181224_36509.shtml)，不由此推定同一形制历朝通用。

穿法示例与独立剪裁分开标注；例如中衣掖入裙腰可保留为搭配示例，不能宣称是新剪裁。装饰繁复或穿着完整的外装不因原始标签写“内衬”就作为核心内衣保留。儿童只在实际需要时另做适龄、完整遮覆的尺寸模板。

### 发型头饰与姿势

与内衬、外衣分别编号、选择和组合。发型按儿童、少年、青年、中年、老年的实际差异规划，但不再乘以角色和四季；普通发型可跨角色使用，官帽、礼冠、头盔等按时代、身份、场合限制搭配。姿势按站、坐、走、劳动、礼仪与职业动作复用，道具另记。选定服装无需重新生成一套相同姿势或发型。

头饰先覆盖主要人物形象，按下表检查缺口，不要求每行独立生图，也不要求每朝沿用同名冠帽。只有资料或造型能支持实质区别时才拆分。

| 覆盖方向 | 应核对的身份与场合 | 复用与拆分规则 |
| --- | --- | --- |
| 帝王 | 日常与重大礼仪 | 日常冠帽与礼冠不能互相替代；按该朝冠服制度核对 |
| 太子与宗室 | 储君、已封爵皇子、亲王等 | 皇子不等于太子；按封爵与礼仪区分，不一律共用帝王冠 |
| 文官 | 常服、朝参或正式礼仪 | 日常帽可能跨身份共用；专属礼冠按品级和场合限制 |
| 军旅 | 将领、士兵及防护需要 | 头盔按防护结构拆分，不凭颜色、金边臆造军衔 |
| 宫廷与贵族女性 | 皇后、妃嫔、宗室女性的礼仪与盛装 | 日常盛装髻不能冒充专属礼冠；等级、婚姻或场合有依据才细分 |
| 市井与家宅 | 商人、伙计、农人、工匠、家仆、侍女等 | 素髻、简簪、包头巾按适配共用，不一职业一套 |
| 僧道 | 僧众、住持、道士、道姑 | 住持不另造基础头型；剃发只作发式说明或姿势层参考，不生成带脸“头饰”；宗教冠饰按时代核对 |
| 行旅与表演 | 行旅者、护送商旅者、乐舞人物 | 笠帽、绦带等按用途共享，影视设计单列标记 |
| 年龄 | 儿童、少年、成年及老年 | 保留有结构区别的适龄发式；年龄盘点不能替代身份覆盖 |

发髻和冠帽若同属头部空间，先核对是否可同时佩戴，不能把两个完整头饰直接叠放。原有带脸的发型参考可保留历史状态；后续新生成按无人物规范执行，不能仅改元数据就宣称已经去除人物。

## 四、先规划，再小批生成

1. **盘点**：读取当前目录、已有图像和历史筛选清单，明确哪些已有、哪些需复核、哪些确实缺失。
2. **归并**：列代表性角色与常规性别，将需求归并到独特衣型；每个候选注明“复用／新增／暂缓”及原因。
3. **排序**：优先缺失的基础男女衣型与共享内衬，再处理有实质差异的礼仪、职业、军旅和季节功能款；特殊身份、儿童尺寸与影视变体按需追加。
4. **定本批范围**：用户指定数量或角色时严格沿用；已授权生图但未指定批量时，默认每批 4–8 组，每组为一种衣型的四视角，不是 4–8 个角色的全部组合。只有“整理／总结”请求时仅交付规划，不启动生图。
5. **生成与比较**：本批完成后，和已有库做视觉比较；明显重复项不继续扩展颜色、季节或另一性别。质量不足的先修正，再追加新衣型。
6. **续批**：按已经授权的范围继续；用户说“继续”时从当前清单下一批独特缺项接续，不恢复旧全量矩阵。当前批结束不自动扩展到未指定朝代或所有角色。

每批清单使用以下字段；这是文档记录格式，不代表 catalog 已支持所有字段：

| 计划编号／已有素材 ID | 时期与地域 | 部件与衣型 | 性别／年龄 | 可复用角色 | 场合／适用季节 | 复用／新增／暂缓 | 与已有款的实质差异 | 资料与待核项 | 图片状态 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 待分配 | 指定分期 | 外衣：窄袖工作短衣 | 男／成年 | 伙计、家仆等 | 日常劳动／春夏 | 先查已有款 | 没有独特差异则复用 | 来源或待考证 | 未生成 |

四季搭配另用“角色／性别／场合／季节 → 内衬 ID + 外衣 ID + 适配外层 + 发型 ID + 姿势 ID”记录。文字方案可以完整，图片只生成去重后的必要款式。

## 五、图片验收与数量口径

- 服装统一为无人物、无可见模特支架的纯服装展示，保留男女剪裁区别。领口、袖口和鞋口中不得残留皮肤或人体；去除头部、发型、冠帽、头盔及兵器、职业道具，保留服装、腰带、护甲与鞋履。发型头饰另选，名称按衣型，礼仪和职业限制写入用途。
- 一组衣型交付正面、斜侧、侧面、背面四张独立 PNG，支持自由切换；四宫格只作源图或对比预览。
- 按实际分隔线裁切，不盲目等分；检查人物、脚部、衣摆是否完整，有无分隔线或相邻格残片。
- 比较四视角的领襟、系带、袖口、层次、颜色、纹样和比例一致性，再与全库候选比较轮廓重复。
- 保留原图、实际提示词、来源与裁切记录。图片状态区分未生成、待裁切、待复核、视角复核通过；历史核对状态另记。
- 若需要清理已有库，默认采用可追溯的归档及替代映射；用户明确要求永久删除时，删除对应原图、裁切图及旧总览，不留图片归档，只保留最小替代与删除结果。筛选建议不等于已执行清理。
- 分别统计角色覆盖数、独特外衣数、共享内衬数、头饰发型数、实际视角文件数、复用关系、待修和待生成项。规划数量、建议保留数量、已入库数量、质检通过数量不能混称。
- 同一素材被多个角色或多个季节引用，只计一组。不得用“角色 × 男女 × 四季 × 内外衣”的旧分母判断新方案完成度。

## 八、后续直接复用的请求

每个新朝代按固定顺序交付以下六部分，确保只输入朝代也能得到相同格式的结果：

1. **时期说明**：朝代、选取分期、地域、资料来源；不适用的身份和影视称谓另列。
2. **角色覆盖表**：角色、常规性别、年龄范围、场合、可复用衣型、头饰类型、身份限制。覆盖五大角色类及僧道、儿童等主要形象；不把角色表直接作为生图队列。
3. **素材清单**：外衣、共享内衬、发型头饰分表；逐项记录形制特征、来源／待核项、实质差异、已有 ID、复用／新增／暂缓和图片状态。
4. **四季与组合表**：每个外衣分类已确认的适用季节与可用素材；不要求每类四季齐全；内衬不分季节。每个主要角色至少给一个合法搭配示例，按适用场合补季节方案。
5. **分批执行清单**：按缺口优先级排列，本批 4–8 组或用户指定数量；先完成一批的四视图检查和去重，再接下一批，不将所有组合同时送去生图。
6. **验收统计**：角色覆盖、外衣组数、内衬组数、头饰组数、独立视图数、待补、待修与归档替代项；图像质量、去人物检查和历史考证分别报告。

组合表统一字段：`朝代／分期｜角色｜性别／年龄｜场合｜季节｜内衬 ID｜外衣 ID｜适配外层（可选）｜发髻／冠帽 ID｜姿势／道具（可选）｜适配限制｜待补项`。尚无图片时用明确的计划编号，不冒充已入库 ID；现有外衣已含某层时，注明内衬隐藏或已包含，避免重复叠穿。组合说明不等于已生成成品人物图。

可直接复制的完整指令：

```text
朝代：【填写朝代，可只填“宋朝”】
本次任务：【整理完整规划／生成首批／继续已授权批次】；未指定时先整理规划。

遵循 docs/guides/dynasty-reference-workflow.md，沿用唐朝整理后的方法，为该朝代建立独立、可组合的参考库。
1. 先核对已有目录和史料，明确代表分期与地域；按该朝实际制度整理主要角色及常规性别，不为少数个例展开另一性别，不照搬唐朝形制、数量或旧素材。
2. 按“时期说明、角色覆盖、素材清单、四季与组合、批次计划、验收统计”六部分输出。覆盖宫廷宗室、官府军旅、市井民生、家宅人物、江湖创作，并检查僧道、儿童等主要形象。
3. 外衣按衣型／用途分类，不一角色一套；换颜色、身份名字或季节标签不新增。四季保持相同分类，结构相同可共用，有可见层次、保暖、防护或礼仪差异才新增；无匹配如实显示，不按季节空格派生补图任务，不跨用途凑数。
4. 内衬按男女版型和领襟、袖型、衣长、裙裤结构共享，不分角色与四季；穿法示例不算新剪裁。儿童保留独立比例，老人优先复用成人衣型。
5. 头饰优先覆盖帝王、太子／宗室、文官、军旅、宫廷女性、平民劳作、僧道、行旅与舞乐；区分日常与礼仪，不每角色各造一顶，不按四季生成。基础发式按结构和年龄需要精简。
```

## 衣型用途与季节覆盖补充

去重不得合并用途和结构有明显差异的日常、礼仪、职业或劳作服。唐朝僧衣分为“僧人日常与劳作衣”：长衣 C262、C301、C302，短衣复用 C258，另有 C305、C306；以及“法会礼仪僧衣”：C201、C263、C291、C292。C263 以大袖层叠结构保留，重复季节款 C303、C304 归档。住持是职务，袈裟非住持专属；不得将影视少林制服当成唐代复原。季节按结构差异选择，不强制四季齐全，长衣与短衣保留实际结构差异，详见季节覆盖。后续只对确认缺少的独特衣型标记待补。

同一朝代、性别的外衣先固定衣型／用途分类，再列季节可用款。允许春夏、春秋共用；缺项不以跨用途图片填充，也不将每个角色机械乘以四季。头饰须同时盘点身份与场合覆盖，年龄覆盖不能代替官帽、军盔、宗教及礼仪头饰覆盖。
