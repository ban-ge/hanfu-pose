[English](song-character-reference.en.md)

本示例按 [精简生成规范](dynasty-reference-workflow.md) 使用：角色表用于规划组合，不逐角色、逐性别、逐季生图；共享内衬不分四季，外衣只按独特结构新增，实际图片按当前授权范围分批制作。

## 范围与依据

此清单用于生成独立、可组合的角色设计参考，分为北宋（960—1127）和南宋（1127—1279）；默认场景为宋朝汉地城市与乡村。地域、阶层及时间不同会改变穿着，不能把某个墓葬的衣物推广给所有人物。辽、金、西夏等并存政权应另建各自的资料和服饰条目。

资料起点：

- 中国丝绸博物馆的[南宋周氏墓褙子和围裹式两片裙复原研习](https://www.chinasilkmuseum.com/yg/info_13.aspx?itemid=31106)：提供特定南宋女性墓葬的褙子和裙装结构线索，不能直接推断各阶层的服饰。
- 中国丝绸博物馆的[素罗单衣](https://www.chinasilkmuseum.com/gskt/info_319.aspx?itemid=28354)：可查衣物材料与出土背景；适用范围限于所讨论的实物和相关资料。
- 国家博物馆的[中国古代服饰文化](https://www.chnmuseum.cn/portals/0/web/zt/202102gdfsh/)：提供古代服饰及宋代并存政权的展示线索。
- 故宫博物院的[《清明上河图》相关研究](https://www.dpm.org.cn/forum_detail/99722.html)：提供北宋城市与人物图像线索；绘画是经过艺术处理的图像，不等同于完整的穿衣制度。
- 浙江省社科联的[赵伯澐墓出土服饰介绍](https://www.zjskw.gov.cn/art/2022/3/18/art_1229514868_45741.html)：提供南宋特定宗室士大夫服饰线索，不能直接套用至普通市民。

以下条目是**参考设计方案，不是已逐项证实的宋人复原**。角色称谓中“店小二”“丫鬟”等方便搜索，“大侠”“夜行者”则是创作角色；性别标记表示拟制作的造型，不证明历史上的任职情况。服制、装饰、配色、礼仪等级和女性从业情形须按具体资料复核。

## 四季内外搭规则

此表是设计起点，按下方角色的工作条件及地域调整；不是已经考证的四季统一着装制度。内衣与外衣分别编号和保存，但相同衣型直接复用，不为各季重复生成内衬。下表是搭配说明，不是生图任务表。

| 季节 | 内衣内衬设计 | 外衣与下装设计 | 配套 |
| --- | --- | --- | --- |
| 春 | 薄中衣及衬裤或内裙，领袖整洁 | 单层衣衫、衫裙或衣裤；按角色加薄外衫 | 布鞋；劳动者衣袖和裤脚便于行动 |
| 夏 | 轻薄透气中衣及衬裤或内裙 | 减少夹层，以轻薄织物表现；礼仪角色仍按场合设置层次 | 轻便鞋履；材质和身份匹配需核对 |
| 秋 | 中等厚度中衣和衬裤或内裙 | 在基础款上增加夹层或外衫 | 布鞋或靴履按角色和场合设计 |
| 冬 | 较厚中衣、衬裤或内裙 | 夹衣、保暖外衫或絮衣设计；有需要时加披覆层 | 保暖鞋履；军事护具与保暖衣分层 |

内搭默认选择朴素中衣、衬裤或内裙；需要研究女性贴身衣物时另列专门条目，依据出土实物核对名称、结构与组合关系，不把外衣轮廓当成内衣复原。四季层次须根据实际天气与阶层调整。

## 姿势、发型与视角素材计划

- 姿势先覆盖：自然站立、行走、端坐、行礼、整理衣袖、持书、端托盘、挑担、手持工具、牵马和站岗。道具与姿势分开标注；具体礼仪动作需考证。
- 发型头饰先覆盖：简束发、布巾、普通盘髻、朴素簪饰、文士巾帽、官帽候选、礼仪冠饰候选、军旅头盔候选、儿童发式。名称及使用情境需各自核对，不按现代外观推断品级。
- 本批选定的独特姿势、内搭、外衣、发型头饰分别制作正面、斜侧、侧面、背面四张 PNG；不得把一张合成图作为四张独立图交付。
- 建议每条记录 `朝代 / 分期 / 地域 / 角色 / 类型 / 造型 / 年龄 / 场景 / 季节 / 部件 / 名称 / 结构 / 资料 / 图片状态 / 审核备注`。

## 示例组合

**南宋题材成年女性侍女，春季工作场景**：简髻与布带 + 素色工作短衫与长裙（外衣）+ 薄中衣与内裙（独立内搭）+ 站立托盘姿势。各组件分别选用对应视角；这只是待生成的概念组合，不是已经复原的文物套装。

## 当前交付状态

宋朝现有 **43 组、172 张独立视角**：25 组外衣、2 组跨季共享内衬、16 组头饰／发髻。18 组保留款已去人物，新增 15 组外衣与 10 组身份头饰。7 组删减素材及 18 组旧人物版本已按用户要求永久删除，旧总览与元数据归档同步清除。
