# 汉服素材制作与同步

[English](SKILL.en.md)

## 原图归属

以 hanfu-pose 为 GitHub 开源素材源库，cgi-image-hanfu 为网站消费库。参考 Shisei 的独立角度文件、机器可读目录和派生尺寸分层。先按编号与角度在源库保存足尺寸原图，更新对应目录索引，再从实际落盘的原图导出网站文件。服装与内搭按 data/garment-images.json 定位，图鉴资料按 data/catalog.json 定位。

存量迁移先比对两边的素材编号、造型、角度与版本。如果最新通过验收的素材只在网站库，先回填源库，再从源库导出。用最新版覆盖同款同角度的旧原图、预览、缩略图及仍被生成页引用的文件。保持收藏、草稿、生成记录引用正确。编号重排时对照迁移前后的实际素材身份，验证引用后移除旧别名。

## 生图与交付

- 每个角度分别生成一张 9:16 竖图。模型输出尺寸有差异时等比调整，在源库交付 900 × 1600 px 原图。保留完整轮廓、以主体居中构图，宽幅衣袖与头饰按宽度留白。优先从生成原稿等比取景，避免用纯色填充凑比例。验收时同时检查画面内四边有无补边接缝，宽构图须保全人物和道具。用单角度原图制作预览和缩略图，禁止将拼板裁作新生成的独立视角。
- 服装、内搭及发型头饰使用正面、斜侧、侧面、背面（front、diag、side、back）。服饰纯白背景、去人物，四角度保持同款形制、用色、纹样与细节。适合搭鞋且缺鞋时将符合时代与身份的同一双鞋搭入整套。发髻保留头发与佩饰，冠帽盔独立展示，去除脸、颈和支架。
- 姿势使用正面、斜侧、侧面、俯拍、仰拍（front、diag、side、high、low）。统一白模与背景，保持动作、左右肢体、重心、道具和接触关系。拟拍示例单独保存为同姿势照片，构图保留人物及关键道具。按当前任务范围安排批次，暂缓的类别仅在用户恢复对应工作时处理。
- 网站放大预览与生成引用使用 900 × 1600 px 文件。服饰缩略图及拟拍缩略图由对应预览等比缩为 360 × 640 px。头饰缩略图沿用该类别已确认尺寸。网站服饰和头饰预览使用「编号-角度-preview.webp」，缩略图使用「编号-角度-thumb.webp」。姿势按角度 JPG 取图，example-full.jpg 为拟拍大图，example.jpg 为拟拍缩略图。
- 服饰身份、影视参考、配色、四季差异及重复款合并沿用源库 docs/guides/dynasty-reference-workflow.md。存量等比重排与逐角度重新生图应分别统计。

## 入库验收

逐组对照原款与角度，检查主体、饰物和鞋履完整，投影视角合理，颜色及尺寸一致。直接读取图片像素尺寸，检查全部源文件、网站预览、缩略图和实际页面所用的生成引用路径。核验导出文件与导入结果的校验和，核对本地目录或数据库的生效记录。以已验收且成功导入的组数计进度，逐组继续。对外发布按用户单独授权执行。
